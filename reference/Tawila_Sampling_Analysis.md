## Detailed Calculations

### Margin of Error Formula

```
Margin of Error (e) = Z × √(p × (1-p) × DEFF / n)

Where:
  Z = 1.96 (for 95% confidence level)
  p = 0.5 (worst case, maximum variance)
  DEFF = 2.0 (design effect for cluster sampling)
  n = sample size
```

### Alternative Formulation Using Effective Sample Size

```
Effective Sample Size (n_eff) = n / DEFF

Margin of Error (e) = Z × √(p × (1-p) / n_eff)
                    = 1.96 × √(0.25 / n_eff)
```

### Design Effect (DEFF)

The design effect accounts for increased variance due to cluster sampling:

```
DEFF = 1 + (m - 1) × ICC

Where:
  m = average cluster size
  ICC = intracluster correlation coefficient

Assumed DEFF = 2.0 for all camps
```

**Justification for DEFF=2.0:**
- Typical range for humanitarian WASH surveys: 1.5-3.0
- Cluster sizes: 13-21 HH (modest)
- ICC assumption: ~0.05-0.10 (moderate homogeneity)
- Conservative but reasonable estimate

### Systematic Sampling Protocol

**For each cluster:**

1. **Define cluster boundaries**
   - Divide camp into geographic zones/segments
   - Use camp maps, GPS coordinates, or visible landmarks
   - Ensure clusters cover entire camp without gaps

2. **Select random start point**
   - Generate random number between 1 and k
   - Example: If k=21, random start might be "7th household"
   - Enumerator walks into cluster and counts to start point

3. **Follow serpentine (zig-zag) walk**
   ```
   Start → HH1 → HH2 → HH3 ... HH7 [SELECT]
             ↓
   Row 2 ← [Continue counting]
             ↓
   Row 3 → [Every k-th household selected]
   ```

4. **Systematic selection**
   - Count every household encountered
   - Select every k-th household for interview
   - Continue until cluster quota reached (e.g., 20 HH)

5. **Replacement protocol**
   - If selected HH is empty/demolished: Skip, select next k-th HH
   - If no one home after 2 visits: Replace with immediate neighbor
   - If refusal: Document reason, replace with next nearest HH
   - Maximum 1 replacement per originally selected HH
   - Record all replacements with reason codes

### Quality Assurance

**Daily checks:**
- GPS coordinates collected for all interviews
- Data uploaded to server by end of day
- Automated logical checks (e.g., age ranges, skip patterns)
- Supervisor reviews sample of interviews

**Verification protocol:**
- 10% of households randomly selected for resurvey

**Data validation:**
- Check for outliers (e.g., water consumption >100 L/capita/day)
- Verify completeness (missing data <5%)
- Validate GPS coordinates fall within camp boundaries

### Appendix A: Sample Size Calculation Formula

**For proportions with cluster sampling:**

```
n = (Z² × p × (1-p) × DEFF) / e²

Where:
  n = required sample size
  Z = 1.96 (for 95% confidence)
  p = expected proportion (0.5 for maximum variance)
  DEFF = design effect (2.0)
  e = margin of error (0.05 for ±5%)

For ±5% MoE:
n = (1.96² × 0.5 × 0.5 × 2.0) / 0.05²
n = (3.8416 × 0.25 × 2.0) / 0.0025
n = 1.9208 / 0.0025
n = 768.32 ≈ 768 households

For ±5.4% MoE:
n = (1.96² × 0.5 × 0.5 × 2.0) / 0.054²
n = 1.9208 / 0.002916
n = 658.7 ≈ 659 households
```

**Note:** Actual sample of 652 is close to calculated 659, accounting for practical allocation constraints.

### Appendix B: Design Effect (DEFF) Justification

**Formula:**
```
DEFF = 1 + (m - 1) × ICC

Where:
  m = average cluster size
  ICC = intracluster correlation coefficient
```

**For this survey:**
- Average cluster size: m ≈ 19 HH
- Assumed ICC: 0.05-0.10 (typical for WASH indicators)

**Calculation:**
```
With ICC = 0.05: DEFF = 1 + (19-1) × 0.05 = 1.90 ≈ 2.0
With ICC = 0.10: DEFF = 1 + (19-1) × 0.10 = 2.80

Conservative estimate: DEFF = 2.0
```

**Rationale:**
- IDP camps typically have moderate within-camp homogeneity
- WASH services often shared within geographic areas
- DEFF = 2.0 is standard for humanitarian cluster surveys
- If actual DEFF < 2.0, precision will be better than reported
- If actual DEFF > 2.0, precision will be slightly worse

**Post-survey:** Calculate actual DEFF from data for future surveys.

### Appendix C: Comparison to Alternative Sampling Methods

**Why not simple random sampling?**
- Requires complete household listing (not available)
- Logistically infeasible in large IDP camps
- Systematic sampling is acceptable approximation

**Why not pure cluster sampling (two-stage)?**
- Would require randomly selecting clusters (Stage 1)
- Higher DEFF (typically 2.5-3.0)
- Current approach surveys all geographic zones
- More similar to stratified systematic sampling

**Why not proportionate to size (PPS) sampling?**
- Requires accurate cluster size estimates (not reliable)
- Adds complexity without clear benefit
- Equal allocation within camps is simpler

**Selected approach:** Stratified systematic sampling with proportional allocation
- Camps as strata
- Systematic sampling within camps
- Proportional allocation by population
- Design effect accounts for clustering

### Appendix E: Key Terminology

**Confidence Interval (CI):** Range within which true population value likely falls (95% CI = 95% probability)

**Design Effect (DEFF):** Factor by which variance increases due to cluster sampling (compared to simple random sampling)

**Effective Sample Size:** Actual sample size divided by DEFF, representing equivalent simple random sample

**Margin of Error (MoE):** Half-width of confidence interval (e.g., ±5% means CI spans 10 percentage points)

**Systematic Sampling:** Selecting every k-th unit from a list or spatial arrangement

**Cluster:** Geographic area containing multiple households, used as primary sampling unit

**Intracluster Correlation (ICC):** Measure of similarity among households within the same cluster

**Proportional Allocation:** Sample distribution matching population distribution across strata

**k (sampling interval):** The interval for systematic sampling (e.g., k=21 means "every 21st household")
